Work · Case study

A private app, built end to end.

Royal Vault is a private web app built for two people: encrypted messaging, files, notes and a set of personal tools behind a single password, with a native iOS shell that adds Face ID. I designed and built all of it.

Role
Design · full-stack development · iOS shell
Areas
Technology · Design
Built with
Node.js, Express, Socket.IO, PostgreSQL, Capacitor
Status
Private; not open to the public

What it is

A messaging and personal-tools app that lives on its own server rather than inside someone else’s platform. Messages are encrypted at rest, uploads are re-encoded server-side with metadata stripped, and the whole thing sits behind a password gate and session cookies.

What I built

  • Real-time chat over Socket.IO with push notifications, read states, embeds and search across an index the server maintains.
  • A media pipeline that accepts photos and video, converts HEIC and transcodes with FFmpeg, and serves everything session-gated.
  • An encrypted password manager, a notes and journal space, and a PDF statement generator.
  • Thirteen colour themes, a service worker for offline shell loading, and a guest mode with reduced access.
  • A Capacitor iOS wrapper with a Face ID gate and an app-switcher privacy cover, loading the live site so web updates ship to the app without a rebuild.
  • An audit log and a test suite for the security-sensitive parts.

What I learned

Building for two people is harder than building for a crowd, because there is nowhere to hide a rough edge. It taught me to take security seriously as a design problem: what gets stored, what gets stripped, who can see what, and how to make that invisible to the person using it.

Work · Case study

A brand, and the systems that run it.

AVNT started as a name, a monogram and a wordmark. It became a small operation supporting online project teams, and I built the software it runs on: an internal operations dashboard, a public website with its own content system, and a Discord bot.

Role
Founder · designer · developer
Areas
Business · Design · Technology
Built with
Next.js, TypeScript, PostgreSQL, Prisma, Clerk, Python
Status
Private repositories; live links to be added

Identity

The brand is a monogram and a wordmark, cut in a heavy geometric sans and exported in black and white for every surface it appears on. It was the first thing I made, and the least important: a brand is mostly the routines behind it.

Ops Central

  • An internal operations dashboard with two roles, admin and secretary, so a second person can run the day-to-day with their own account.
  • A task and question board that moves work from open to done and writes a log entry when it does.
  • A contacts directory for developers with skill tags and a draft workflow for entries pushed in by the bot.
  • A visual Discord server builder that edits channels, roles and permissions as reusable templates.
  • A shared ban list that works in both directions between the dashboard and Discord, with evidence attached.
  • A staff directory, an automatically generated weekly log, and a quick-links hub the bot can answer from.

The website

A public site built in Next.js with PostgreSQL and Prisma, Clerk for authentication, and object storage for uploads. Its admin area is a small content system for projects, metrics, leadership, operating signals and network links, with unit tests and end-to-end tests.

The bot

A Python Discord bot with tickets, an autoresponder, role commands, global bans and a natural-language layer: a moderator can ask it in plain English to do things, and it selects, filters and acts through a fixed set of authorised tools.

What I learned

Giving a second person their own account and their own log taught me more about running something than the logo did. Business, for me, is the discipline of turning an interest into something that keeps working when I am not looking at it.
